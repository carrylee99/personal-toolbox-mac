# 记性不好 · 深色桌面设计规范

方向：用户确认的 B，参考 Linear 的石墨灰层次。沿用 Electron 31 和原生 HTML/CSS/JavaScript。

依据：已安装 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)，版本 `28b3b8dee8c976df4fa3e94aed4e092ad43fcb03`。使用 design-system 检索建立视觉规范，并核对 dark mode contrast、keyboard focus modal 指引。检索中的营销页布局不适合桌面工具，不予采用。

## 颜色与层级

统一变量位于 `src/design-tokens.css`。

| 用途 | 色值 |
| --- | --- |
| 背景 / 侧栏 | #161719 / #121315 |
| 内容面板 / 次级面板 | #1D1E21 / #202125 |
| 普通分隔 / 输入边界 | #34353B / #737680 |
| 正文 / 次要文字 | #EFF0F3 / #A1A3AE |
| 主操作 / 焦点环 | #6268DE / #A8ACFF |
| 成功 / 失败 / 提醒 | #80D2AA / #FF959E / #E9C27D |

红绿黄同时配合文字标签、差异标记；不只依靠颜色表达状态。正文与背景对比度目标 ≥ 4.5:1，可交互边界/焦点 ≥ 3:1。暗色的填充按钮采用白字，辅助强调采用较亮紫色文字。

## 文字、间距与组件

- macOS 系统字体，无外部字体请求。模块标题 22px、卡片标题 17–20px、主要内容 14–16px、辅助说明 12–13px。
- 基础间距 4/8px；面板间距 16/24px；控件圆角 6px，面板 8–12px，刘海下角 20px。
- 侧栏 176px，可收起至 68px；单色 SVG 图标统一 18px、1.65px 描边。
- 备忘使用分组行列表；删除操作放在详情。设置按常规、外观、快捷键、备忘提醒、数据配置分组。
- 空列表、失败保留输入、禁用、防重入、悬停与键盘焦点都有对应状态。
- 悬停/选择仅改变背景与边界，不移动按钮；尊重 `prefers-reduced-motion`。

## 刘海行为

收起时只有黑色区域。主屏居中，以逻辑像素定位；内容避开顶部至少 48px 的菜单栏/刘海安全区。悬停展示不激活窗口；移出 300ms 后关闭，回到区域取消关闭。键盘打开可 Tab 操作，Esc/再次快捷键/外部点击关闭。圆角外穿透鼠标。

待办采用主列表共用的七天延期判断，更新时间倒序，排除完成与延期。快速新增复用极速备忘；详情打开主窗口。设置禁用可移除刘海，退出释放窗口、快捷键和监听器。

## 兼容

首次升级迁移到精致深色；配置 `appearanceVersion: 1` 后保留用户后续主题选择。自然/经典主题继续可选。应用名称、图标、存储格式和其他业务规则不变。

## 0.2.1 · 已选方案三

刘海为左右等宽的月历/当日待办双栏，480×300（安全区高于48px时高度随之增加），下角18px。月份切换与收起使用11px文字按钮，避免原生窗口图标不可见。日期按本地截止日归组；无期限放入未安排。日期页新增明确显示并保存当天23:59，已有极速备忘草稿保持原截止时间。

原生窗口保持展开尺寸，透明区域按鼠标位置穿透。移出300ms后轮廓收拢180ms，内容淡出100ms；展开220ms，内容淡入140ms。收拢中返回可反向展开；保留减少动画偏好。不再在退出末尾直接缩小原生窗口。

## 0.2.2 · 多屏行为

每块连接的显示器顶部均有独立刘海，保持原逻辑尺寸和各自安全区。悬停/退出状态各自维护；待办数据广播同步。Option+T 在鼠标所在显示器展开或收起，避免多个键盘面板竞争焦点；从刘海新增时，极速备忘在来源屏幕居中。插拔、重排、缩放变化按显示器ID更新窗口；统一开关控制全部刘海。

## 0.2.5 · 紧凑双栏

本轮方案一：内容480×284，列宽196/284，内建屏透明避让区另外计算。任务区头部40px、列表192px、底部30px；32px一行，首屏6项。标题17px、任务13px、期限11px。完成圆圈16px、鼠标热区28px；今日期限显示时分，其他日期显示月日，完整截止时间保留在提示和无障碍名称中。键盘聚焦任务时显示完整标题提示，不改变行高。普通待办口径、默认全部、存储及多屏交互沿用既有实现。

## 0.2.3 · 隐藏入口

收起时完全透明，取消260×48常驻黑色块。每屏顶部中央160×4逻辑像素仅用于悬停感应，透明窗口不拦截点击；快捷键继续在鼠标所在屏幕展开。展开日历仍为480×300及既有安全区。
