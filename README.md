# 记性不好

一个基于 Electron 的 macOS 个人效率工具，包含主面板、每日备忘、文本对比、冒烟记录和刘海待办。

## 功能

- 刘海待办与日历
  - 480 × 284 紧凑双栏（首屏 6 项，更多滚动查看）：左侧月历，右侧默认全部普通未完成待办；点日期才筛选，重新展开恢复全部
  - 全部视图新增不设期限；日期页新增带入当天 23:59 截止时间；支持方向键、Page Up/Down 切换日期与月份
  - 连续收拢轮廓与淡出内容，收起中途移回可直接展开
  - 平时完全隐藏；每块屏幕最上沿正中保留 160 × 4 像素感应区，透明区域不挡点击；插拔屏幕自动适配，主窗口关闭后仍可唤出
  - 鼠标移入展开，移出约 300ms 后收起；悬停不抢焦点
  - 默认 `Option + T` 在鼠标所在屏幕展开/收起，可在「设置 → 快捷键」修改
  - 快捷键打开后保持展开；Esc、外部点击或鼠标进入后移出可收起
  - 与普通未完成待办同步，排除延期处理；支持完成、详情、极速新增
  - 「设置 → 常规」可关闭刘海，也可点击「展开刘海」预览
- 精致深色外观
  - 统一主界面、详情、对比和极速备忘的深色层次与 SVG 导航图标
  - 首次升级默认深色；自然、经典主题继续可选，后续选择会保留
  - 支持键盘焦点、减少动画偏好和语义差异颜色
- 冒烟记录
  - 按版本、场景、Case、步骤组织冒烟用例
  - 支持步骤成功、失败、未执行状态记录
  - 支持失败原因、步骤排序、Case 复制、批量删除
  - 支持导入结构化 `smoke-run-plan.md`
  - 支持导出当前版本为 Markdown 汇总文档
- 每日备忘
  - 快速新增待办
  - 支持标题和详情字段
  - 支持截止时间和到期通知
  - 支持超过 7 天未更新的待办自动进入延期处理
  - 支持完成、恢复、删除
  - 支持 JSON 导入和导出
  - 支持极速备忘浮窗和自定义快捷键
- 主面板
  - 当前时间
  - 今日待办数量
  - 每日诗词缓存
- 常规设置
  - 支持开机自启动
  - 支持主题、数据目录和全局快捷键配置

## 数据存储

应用会连接一个本地目录作为数据根目录。首次启动默认使用应用私有目录：
`~/Library/Application Support/记性不好/Vault`。可以在应用设置中修改该目录，备忘数据和冒烟数据都会跟随这个根目录。老版本 `个人工具箱` 的配置会在首次启动时自动迁移并沿用原 Vault。

数据文件写入 Vault 内：

- 冒烟记录：`.personal-toolbox/smoke.json`
- 每日备忘：`.personal-toolbox/memo.json`
- 冒烟 Case Markdown：`Smoke Tests/<版本>/<场景>/<Case>.md`

这些本地数据目录不会提交到仓库。

## 备忘录导入格式

导入文件使用 JSON。`notes` 为必填数组；同 `id` 会更新已有备忘，没有 `id` 会创建新备忘。

```json
{
  "schemaVersion": 1,
  "notes": [
    {
      "title": "跟进双边履约冒烟结果",
      "detail": "补充失败 case 的复现路径和截图。",
      "completed": false,
      "createdAt": "2026-06-10T09:00:00.000+08:00",
      "updatedAt": "2026-06-10T09:20:00.000+08:00",
      "completedAt": null,
      "dueAt": "2026-06-10T18:30:00.000+08:00",
      "deadlineNotifiedAt": null
    }
  ]
}
```

## 极速备忘：用文字设置截止时间（0.2.6）

在内容后输入 `---` 和时间描述，日期框会实时填入结果；保存成功后只移除识别成功的时间后缀。示例：

- `开发版本需求---后天截止`：后天 23:59。
- `提交方案---明天下午三点半`：明天 15:30。
- `版本发布---下周五18:00前`：下一自然周的周五 18:00。
- `检查结果---两小时后`、`回访---半小时后`：从输入该表达时起计算。
- `整理资料---三天后`、`月度总结---月底`：指定日期 23:59。
- `项目验收---2027年1月2日`、`复查---11/5 09:30`：具体日期，可带时刻。

只写日期默认 23:59；省略年份使用今年，只写时刻使用今天。未加“本/下”的星期使用最近的对应星期（含今天）。所有日期按本机时区解释，不联网。

可在右上角手动设置或清空日期；只修改正文会保留手动日期，修改时间表达则重新识别。删除时间后缀会恢复进入窗口时的日期（或最近手动设置的日期）。多行备忘保留后续详情，以第一个识别符所在行的剩余文字作为时间描述。

“尽快”“下周”“明天下午”等没有确定日期或时刻的表达，以及无效日期，会提示修改或手动设置，确认前不保存。手动设置后允许保存无法识别的原文，避免内容丢失。


### 自定义截止时间识别符（0.2.7）

在 **设置 → 常规 → 极速备忘 → 截止时间识别符** 输入并保存，例如改为 `@@` 后使用 `开发版本需求@@后天截止`。支持 1–16 个非空白字符，按字面匹配；修改后立即生效并在重启后保留。“恢复默认”会保存为 `---`。旧配置自动使用默认识别符，既有待办内容和截止时间不变。识别采用内容中首次出现的识别符，后面的日期或时刻可包含相同符号。


### 极速备忘精简外观（0.2.8）

移除底部常驻日期说明和快捷键提示，截止时间直接显示在右上角。窗口高度由 220 缩短到 190；保留时间识别失败、保存失败等必要反馈，快捷键和自定义识别符照常可用。


### 刘海悬停延迟（0.2.9）

默认连续悬停顶部中央感应区 2 秒后展开。可在 **设置 → 常规 → 刘海待办 → 悬停展开时间（秒）** 设置 0–10 秒（最多一位小数），保存后所有屏幕立即生效，重启后保留。0 秒表示立即展开。提前移开会取消等待，重新移入从头计时；修改时长、禁用或显示器变化会清除旧计时。快捷键和“展开刘海”按钮仍立即响应，已展开面板的退出动画中移回仍可顺滑恢复。


### 时间表达学习（0.2.10）

极速备忘会把未识别的时间表达保存在 Vault 的 `.personal-toolbox/time-rules.json` 文档中，只记录时间文字，不记录备忘正文。输入停顿约 0.9 秒、离开输入框或尝试保存时记录；相同表达去重。每次新建极速备忘都会重新读取规则文档。

- 初次输入 `任务--今天下午`（以设置中的识别符为准）仍提示未识别。手动选择当天 15:30 并成功保存后，文档记录 `今天下午 → 今天T15:30`；下次输入会自动填入当天 15:30，跨天会重新计算日期。
- 把未识别表达改写为可识别表达并保存，也会学习最后一条未识别表达与修正的对应关系。含明确日期与模糊时段的表达，保留原来的相对日期；若手选日期与原表达日期不一致，则留待学习。
- 点击「不设截止保存」会保留原文和未识别记录，**不会猜测默认时刻或创建学习规则**。取消草稿也不会学习。
- 没有明确日期含义的任意短语，单凭一次日期选择无法可靠推断重复规则，继续保留为 `pending`；可以改写成可识别的时间表达后保存，形成别名规则。已学习条目标记为 `learned`，记录目标表达与学习时间。
- 规则完全在本地处理，不调用在线 AI，不执行文档内的代码。学习只影响后续新建，不回改已有备忘。
- 记录失败会提示并在保存时重试；规则学习失败不撤销已保存的备忘，也不会允许重复提交。规则文档格式损坏时提示检查文档，不覆盖原文件。

规则适用于极速备忘的文字日期入口；主面板普通新建备忘继续使用手动截止时间。

### 自定义分组（0.2.11）

- 每日备忘顶部点击「新建 / 管理分组」，设置名称、颜色、常用状态和顺序。主窗口显示前三个常用分组，其余在「更多分组」中搜索选择；刘海自 0.2.13 起可横向浏览全部分组。两处分别记住筛选，刘海仍保持六行列表。
- 每条备忘属于一个分组；旧备忘归入「未分组」。详情中可移动分组，组内新增自动带入当前分组。删除分组只将任务移回未分组，不删除任务，也不改变截止时间、完成状态或延期时间。
- 极速备忘首行输入 `开发版本需求 #工作 --- 后天截止`（时间符号以个人设置为准）。方向键选组、Enter 确认，再按 Enter 保存；未知名称需要明确选择「新建」。也可以点击顶部的分组名称更换或清空归属。
- 分组符号必须位于首行行首或空白之后；`C#`、URL 片段及详情中的符号保留原文。名称含空格可用 `#"项目 A"`，或者从顶部选择。每条只支持一个分组标记，多组输入会提示并保留草稿。
- 「设置 → 常规 → 极速备忘 → 分组识别符」可改为 `@`、`@@` 等 1–8 个符号。分组和日期符号不能相同或相互包含。分组标记与日期标记可交换顺序。
- 分组和备忘一起保存在原 `memo.json`，导出包含分组定义。旧版备忘导入仍兼容，同 ID 更新且没有分组字段时保留已有归属。导入同名分组会复用本地分组。

### 上周完成快捷筛选（0.2.12）

进入「每日备忘 → 已完成」，点击「上周完成」即可查看上一个自然周（本地时间周一 00:00 至本周一 00:00 之前）完成的备忘，界面显示具体日期范围。筛选与当前分组、关键词叠加，结果按完成时间倒序展示；点击「全部完成」恢复原列表。恢复为待办的记录立即移出结果。历史数据没有完成时间时，沿用原界面的更新时间/创建时间兼容规则，不回写数据。

### 刘海分组展示优化（0.2.13）

刘海顶部不再只显示两个分组：全部自定义分组按管理顺序排列，鼠标滚轮或触控板横向滚动浏览，方向键和 Home/End 可移动焦点，Enter 选择。右侧固定「⋯」打开更多菜单。菜单对齐待办区域，名称与数量分列，长名称可换行，滚动条采用深色细样式。从菜单选择后，顶部自动滚到对应分组；任务同步刷新保留浏览位置。窗口尺寸和六行待办保持不变。
